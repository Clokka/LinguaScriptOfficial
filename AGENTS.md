
- Verb/word form checks use public.word_forms (UniMorph import + cached analyze-word-form AI results) and sentence_patterns.slots[0].accepts — never suffix heuristics. Why: irregular forms and non-hand-coded languages need exact data.
- UI translation uses the lightweight `src/i18n` (useT, STRINGS) keyed by profile native_language > device choice > browser language; why: reassure non-English beginners without a heavy i18n dependency.
- Vocabulary-coverage thresholds (98 ideal / 95 min / 90 stretch) live only in src/lib/coverage.ts; why: one comprehensible-input rule across recommendations, labels and rails.
- Untranslated UI text is machine-translated at runtime by src/i18n/AutoTranslate (translate-ui function, cached per language on device); mark learning-language text translate="no". Why: switching native language must change the whole app without hand-translating every screen.
- Never block screenshots or screen recording (no FLAG_SECURE, expo-screen-capture preventScreenCapture, or similar) on mobile or web. Why: learners and the team need to capture and share the app at any time; a "security policy" screenshot error comes from device management (Family Link, school/work profile) or Chrome Incognito, not from LinguaScript.
