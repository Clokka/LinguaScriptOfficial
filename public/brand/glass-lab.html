How these are built: Liquid Glass = backdrop-filter + bright inner edge + an SVG lens filter; glassmorphism = stronger blur + see-through white; morph = spring easing (things overshoot a little, then settle). The View Transitions API (web) and Framer Motion layoutId (React) make shared-element morphs easy on the LinguaScript website.
