# Google Play store assets

| Play Console field | File | Size |
|---|---|---|
| App icon | play-icon-512.png | 512×512 |
| Feature graphic | play-feature-graphic-1024x500.png | 1024×500 |
| Phone screenshots (2–8) | phone-screenshots/*.png | 1080×1920 |
| 7-inch tablet screenshots | tablet-7in-screenshots/*.png | 1200×1920 |
| 10-inch tablet screenshots | tablet-10in-screenshots/*.png | 1600×2560 |

Play only accepts PNG/JPG. The SVG originals (sharp at any size) are in svg-originals/.
Screenshots are illustrations of the app's screens; swap in real phone screenshots when you can.
